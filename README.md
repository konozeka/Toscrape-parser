# Toscrape-parser

Парсер книг с books.toscrape.com на Python (requests + BeautifulSoup) с выгрузкой в CSV

## Что делает

- Собирает названия, цены и наличие книг с первой страницы.
- Выгружает данные в CSV-файл.

## Стек

- Python 3
- requests
- BeautifulSoup
- csv

## Как запустить

pip install requests beautifulsoup4
python parser.py

## Результат

Файл books.csv с 20 книгами.
